# Чиновники

Язык программирования: **C++**

## 🎯 Цель проекта

Разработка консольной программы для решения задачи **«Чиновники»**, в которой необходимо определить минимальную стоимость получения лицензии с учётом структуры подчинения чиновников и стоимости получения подписи у каждого из них.

## 📦 Описание

Программа представляет собой консольное приложение на C++, работающее со структурой министерства.

Каждый чиновник имеет:

* номер;
* стоимость получения подписи;
* номер непосредственного начальника;
* список подчинённых.

Один чиновник является главным. Для него номер начальника равен `0`.

Остальные чиновники подчиняются другим чиновникам, образуя древовидную структуру. Для получения лицензии необходимо получить подпись главного чиновника. При этом каждый чиновник требует подпись хотя бы одного непосредственного подчинённого и может требовать определённую сумму в условных единицах.

Задача программы — проверить корректность введённых данных, построить структуру министерства и найти минимальную сумму, необходимую для получения лицензии.

## ✅ Функционал

В программе реализованы следующие возможности:

* ввод данных о чиновниках с клавиатуры;
* загрузка данных из текстового файла;
* создание нового файла с данными;
* случайная генерация корректной структуры министерства;
* проверка корректности введённых данных;
* проверка наличия ровно одного главного чиновника;
* проверка отсутствия циклов в структуре начальников;
* проверка связности структуры министерства;
* построение списка подчинённых для каждого чиновника;
* вывод структуры министерства в виде дерева;
* вычисление минимальной стоимости получения лицензии;
* вывод выбранной цепочки подписей;
* обработка ошибок пользовательского и файлового ввода.

## ⌨️ Ввод данных с клавиатуры

При ручном вводе программа запрашивает:

* количество чиновников `N`;
* стоимость подписи для каждого чиновника;
* номер начальника для каждого чиновника.

Нумерация чиновников начинается с `1`.

Значение начальника `0` означает, что данный чиновник является главным.

## 📄 Формат входного файла

Файл входных данных должен содержать три строки:

```text
N
стоимость_1 стоимость_2 ... стоимость_N
начальник_1 начальник_2 ... начальник_N
```

Пример файла:

```text
5
46 3 7 35 29
0 1 2 2 4
```

В данном примере:

* всего 5 чиновников;
* чиновник 1 является главным;
* чиновник 2 подчиняется чиновнику 1;
* чиновники 3 и 4 подчиняются чиновнику 2;
* чиновник 5 подчиняется чиновнику 4.

## 🌳 Пример структуры министерства

Для приведённого выше примера структура министерства выглядит так:

```text
1
└── 2
    ├── 3
    └── 4
        └── 5
```

Главный чиновник находится в корне дерева. Чиновники без подчинённых являются листьями дерева.

## 🧮 Результат работы

После загрузки корректных данных программа выводит:

* количество чиновников;
* номер главного чиновника;
* список чиновников с их стоимостью подписи и начальником;
* структуру министерства в виде дерева;
* выбранную цепочку подписей;
* минимальную сумму получения лицензии.

Пример результата:

```text
Выбранная цепочка подписей: 3 -> 2 -> 1
Минимальная сумма: 56 у.е.
Порядок получения подписей: 3 -> 2 -> 1
```

## ⚠️ Обработка ошибок

Программа проверяет корректность пользовательского ввода и структуры данных.

Обрабатываются следующие ошибки:

* ввод нецелого значения;
* ввод числа вне допустимого диапазона;
* отсутствие файла;
* неверный формат файла;
* отрицательная стоимость подписи;
* отсутствие главного чиновника;
* наличие нескольких главных чиновников;
* указание чиновника начальником самому себе;
* циклы в структуре начальников;
* несвязная структура министерства.

При возникновении ошибки программа выводит диагностическое сообщение и не завершается аварийно.

## 💡 Примечания

* Количество чиновников должно быть от `1` до `1000`.
* Главный чиновник должен быть ровно один.
* Структура министерства должна быть связным деревом.
* Стоимость подписи не может быть отрицательной.
* `у.е.` означает условные единицы.
* Программа работает через консольный интерфейс.
* Сохранение истории работы не предусмотрено.
* Проект реализован с использованием классов и ручного управления динамической памятью.

## 🏁 Итог

Программа позволяет построить структуру министерства, проверить её корректность и определить минимальную стоимость получения лицензии.
Результатом работы является минимальная сумма и порядок получения подписей от нижнего чиновника к главному.
